# ساخت ابری APK — سه مگا پرامپت

این پروژه یک برنامه ساده WebView است. تصویر مرجع و هر سه مگاپرامپت داخل خود APK قرار می‌گیرند و برنامه برای اجرا به اینترنت یا برنامه جانبی نیاز ندارد.

## ساخت APK با GitHub Actions
1. وارد حساب GitHub شوید و یک مخزن جدید (ترجیحاً Private) بسازید.
2. فایل‌های داخل این پوشه را در ریشه مخزن بارگذاری کنید؛ پوشه `.github` نیز باید بارگذاری شود.
3. به زبانه Actions بروید و در صورت درخواست، فعال‌سازی GitHub Actions را تأیید کنید.
4. از فهرست سمت چپ، `Build Android APK` را انتخاب و `Run workflow` را بزنید.
5. پس از پایان موفق، از پایین صفحه اجرای workflow، بخش Artifacts، فایل `Three-Mega-Prompts-APK` را دانلود و ZIP را استخراج کنید.
6. فایل `app-debug.apk` را روی گوشی نصب کنید.

## مشخصات
- حداقل نسخه هدف‌گذاری‌شده: Android 4.0 (API 14)
- Target SDK: 28 برای حفظ دامنه سازگاری با دستگاه‌های قدیمی
- بدون مجوز اینترنت
- متن‌ها و تصویر به صورت آفلاین داخل APK
- کپی متن از طریق ClipboardManager اندروید

نکته: سازگاری واقعی با تمام دستگاه‌های Android 4 تضمین‌شدنی نیست؛ WebView کارخانه‌ای بعضی دستگاه‌های قدیمی بسیار محدود است. نسخه آزمایشی باید روی گوشی واقعی بررسی شود.
